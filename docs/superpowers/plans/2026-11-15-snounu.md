# Snounu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** تنفيذ منيو سنونو مطابق لمرجع Figma، مع إدارة فعلية ومصادقة Firebase وصور دائمة وتجهيز نشر Vercel وSEO محلي.

**Architecture:** تطبيق Next.js واحد للزوار والإدارة وواجهات الخادم. PostgreSQL هو المصدر الوحيد للمحتوى والرسائل والتقييمات. Firebase Email/Password للمصادقة، وAdmin SDK للتحقق من جلسة الإدارة وclaim snounuAdmin، وStorage للصور؛ Analytics اختياري في المتصفح فقط.

**Tech Stack:** Next.js App Router، React، TypeScript، Tailwind CSS، PostgreSQL، أداة ترحيلات مكتوبة الأنواع، Firebase Web/Admin SDK، أداة تحقق مدخلات، sharp، Vitest، Playwright. تثبت الإصدارات المستقرة والمتوافقة بقفل حزم عند توفر npm، ولا يُنشأ قفل تخميني.

**Spec:** docs/superpowers/specs/2026-11-15-snounu-design.md، مع تحديثات Firebase وGitHub وTailwind وVercel في هذه الخطة وdocs/DEPLOYMENT_AR.md.

## Global Constraints

- منيو عرض مع لوحة إدارة؛ لا دفع أو سلة أو طلب داخلي.
- مكوك: https://makuk.torood.net/ — سنبل: https://sonbol.ps/.
- صفحة تفاصيل مستقلة مع مسار الرئيسية والقائمة والقسم والطبق، بمرجع Figma 2061:15.
- RTL وعملة الشيكل ووضعان فاتح وداكن، واختبار عرض 360 و390 و412 و768 و1024 و1440.
- المفضلة والمظهر محليان، ونجوم التقييم الحقيقية من المقبول فقط؛ التعليق حتى 1000 حرف والنجوم أعداد صحيحة 1–5.
- الصور JPEG/PNG/WebP وبحد 5 MB، تحقق وإعادة ترميز على الخادم؛ لا صور مؤقتة من Figma وقت التشغيل.
- لا كتابة على مشروع Firebase القائم أو المستودع البعيد قبل فحص الحالة الحالية. لا مسح بيانات Taskora أو force push.
- لا تنشر أسرار الخادم أو بيانات الرسائل، ولا تدّعِ جاهزية النشر قبل build والاختبارات.
- حسابات المدير تستخدم Firebase مع claim snounuAdmin=true بدل كلمات مرور PostgreSQL المقترحة سابقًا.

## Review Focus

- رمز Firebase صحيح دون claim إدارة لا يجوز أن يسمح بقراءة أو تعديل خاص.
- فشل PostgreSQL لا يعيد نجاحًا وهميًا للرسائل ولا يستبدل بيانات الإنتاج ببيانات تجريبية.
- إعادة الطلب بالتوازي أو بعد timeout لا تضاعف رسالة أو تقييمًا؛ والمعاملات تحدد أثر التعديل على المتوسط.
- بيئة Preview أو نطاق غير معتمد لا يسرب canonical أو sitemap لإنتاج خاطئ ولا يسمح بالفهرسة.
- تعديل اسم أو أرشفة قسم أو منتج لا يكسر الروابط والعلاقات ولا يترك تقييمات أو مفضلة تكشف منتجًا مخفيًا.

## حالة التحضير الحالية

تمت تهيئة مستودع محلي على setup/snounu وإضافة origin. الحزم والأصول والوصول البعيد لم تتوفر: GitHub وnpm وFigma asset downloads فشلت بالاتصال/EACCES. المهام التالية لم تُنفذ، ولا توجد نتائج اختبار أو build. استئناف التنفيذ يبدأ بإزالة هذا العائق، وليس بإعادة كتابة وثائق موجودة.

## قرارات التنفيذ الموثقة

Firebase يكمّل PostgreSQL ولا يستبدله؛ لا مزامنة مزدوجة للمنيو. Firebase Admin credentials لا يمكن استنتاجها من web config. استخدام Firebase Auth يستبدل جداول كلمات المرور والجلسات المحلية المقترحة سابقًا، ويحتفظ بمتطلبات حماية الإدارة. التصميم هو المرجع البصري، وأي تحسين يركز على الاستجابة والقراءة والحالات الناقصة.

## ما بقي قبل تنفيذ الخطة

إتاحة تنزيل npm وأصول Figma والوصول إلى المستودع البعيد. مفاتيح Firebase الخاصة وقاعدة PostgreSQL وموقع المطعم النهائي ليست مطلوبة لكتابة الواجهة محليًا، لكنها مطلوبة للتحقق من الخدمات والإطلاق الفعلي. لا حاجة لإرسال الأسرار في المحادثة؛ توضع في إعدادات بيئة التشغيل.
